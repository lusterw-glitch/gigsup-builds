# GigsUp test builds

Android APKs only. No source code lives here.

**Install the newest build:** open this link on the phone while signed in to GitHub:

https://github.com/lusterw-glitch/gigsup-builds/releases/latest/download/gigsup.apk

The first time, Android asks to allow installs from your browser. Allow it, then tap Install. Newer builds install over the old one and keep your data.

Every build and what changed: [Releases](https://github.com/lusterw-glitch/gigsup-builds/releases)
